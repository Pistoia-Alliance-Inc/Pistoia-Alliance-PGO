# Definition *(skos:definition)*

An object contrived for a specific purpose. OR: An object that has a specific use. In medicine, wheelchairs, pumps, and artificial limbs are examples of devices.

# Editorial notes

## Summary Expert Alignment *(dcterms:description)*

**Round 1** (2025-02-13)

There is a need for a broad "device" core concept in pharma R&ED. The variety of devices deployed in pharma is enormous, so context is important.

Key discussion points:
- "Device" makes sense as a high-level entry-point label; covers laboratory equipment, production equipment, diagnostic tools, and medical devices.
- NCIT_C62103 (*"An object contrived for a specific purpose"*) was considered pragmatically appropriate despite some concern about breadth.
- An additional option was noted: NCIT_C19238 (*"A manufactured object used to perform diagnostic, therapeutic or research activities"*) — would exclude manufacturing equipment.
- IDMP-O's "medical device" definition is appropriate as a future sub-concept child class.

The group reached consensus on NCIT_C62103 for the Phase 1 "device" concept, with three sub-concepts recommended for Phase 2:
- "Instrument" — laboratory/measurement device for scientific investigation
- "Medical device" — e.g. NCIT_C16830
- "Manufacturing equipment" — tablet manufacturing device (out of scope for R&ED extension)

GitHub issue #37 remains open pending a formal label decision in the PGO repository.

**Outcome:** Consensus on NCIT_C62103. Recommendation submitted to Steering Group.
